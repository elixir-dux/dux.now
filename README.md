# dux.now

Landing page for [Dux](https://github.com/elixir-dux/dux) — distributed DuckDB-native DataFrames for Elixir.

## Setup

Hosted via GitHub Pages. Push to `main` and the GitHub Actions workflow deploys automatically.

To enable Pages on the repo:
1. Go to **Settings → Pages**
2. Set **Source** to **GitHub Actions**

## Local preview

```sh
open index.html
# or
python3 -m http.server 8000
```
